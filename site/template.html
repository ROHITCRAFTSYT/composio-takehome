The agent

What I built, and where a human was needed

STAGE 1 · agent

Researcher

One Claude Haiku agent per app. Tools: Composio web search (Tavily toolkit via composio execute) and a page fetcher. Returns a schema-checked record with a quote per field.

LOOP 1 · code

Consistency lint

Rubric rules: "ready" on a gated app, blocked with no blocker, official MCP without URL, missing evidence, low confidence.

LOOP 2 · code + browser

Evidence check

Re-fetches every cited URL (HTTP → headless Chromium → reader proxy) and checks the quote is really on the page and on a vendor domain.

LOOP 3 · agent

Critic

A fresh Claude Sonnet agent gets the draft + every flag, re-derives access, MCP and verdict on every app from primary docs, fixes flagged fields, and logs each change.

LOOP 4 · human

Gold sample

20 apps (2 per category, seeded random) labelled blind from vendor docs, __GOLD_REVIEW__; both passes scored against it.

Where a human was needed

    Design choices that buy accuracy

    • Agents get page text, not summaries. WebFetch-style tools return a model summary, so "quotes" can't be checked. Our fetcher returns raw text, so every quote is verifiable byte-for-byte.
    • One rubric (RUBRIC.md) shared by researcher, critic and gold labeller. "Accuracy" means agreement with that rubric.
    • Cheap broad pass, stronger review. Pass 1 runs on a small model (Haiku). The critic (Sonnet) re-derives access, MCP and verdict on every app, because those are judgement errors no automatic check can see, and must also fix everything the loops flagged.
    • Composio catalog check per app, so the output says which gaps are real backlog vs. already shipped.
    Verification

    How I know it's right (and where it isn't)

    Accuracy vs the blind gold sample, per field

    Exact match with the gold label on 20 apps. Pass 1 = researcher alone; pass 2 = after lint + evidence check + critic.

    What the loops caught on all 100

    Loops run on every record, not just the sample.

    Every miss, shown

    Fields where the final record disagrees with gold. Some are genuine errors (e.g. a GraphQL API the agent missed, a docs site it never found); others are judgement calls the rubric leaves open (e.g. "paid plan" vs "contact sales" when every plan is sold through a demo).     Run it yourself

    Source, prompts, every record, every tool call and the gold labels are in the repo: github.com/__REPO__

    Inside Claude Code (no API key)

    git clone https://github.com/__REPO__ && cd __REPONAME__ pip install -r requirements.txt && playwright install chromium composio login # Composio CLI, free account claude # then type: /research-apps 1-100 # researcher fan-out /research-apps 1-100 pass2 # loops, then critic on every app

    Headless (Claude Agent SDK)

    export ANTHROPIC_API_KEY=... # or a logged-in Claude Code python -m agent.coverage # Composio catalog check python -m agent.research --apps 1-100 python -m agent.checks --stage pass1 # loops 1-2 python -m agent.critic --apps 1-100 python -m agent.checks --stage pass2 python -m agent.score && python -m agent.build_site
