Headline

  • 83 of 100 apps can be agent toolkits today (72 ready, 11 buildable but production needs vendor review); 17 blocked.
  • The hard part is access, not APIs: 97% have a documented public API, only 79% let a developer get credentials alone. Top blockers: app review (11), paid plan (8), sales/partner (6).
  • 20 apps are not on Composio yet (live catalog check via the Composio CLI); 9 of those can be built right now.

The agent

  • One researcher agent per app; tools are Composio web search (Tavily toolkit via composio execute) and a page fetcher that returns raw text (HTTP → headless browser → reader fallback), so every quote is checkable.
  • Verification loops: rubric lint → evidence check (re-fetches every cited URL, confirms the quote is on the page and on a vendor domain) → critic agent on every app → blind 20-app gold sample.
  • Runnable via a Claude Code slash command (/research-apps 1-100) or headless with the Claude Agent SDK.

Verification

  • Gold sample accuracy (100 graded fields): 78% after the researcher → 83% after the loops; access 55% → 65%, verdict 80% → 90%.
  • 713 of 715 cited quotes found on the cited page; 95% of graded fields backed by a vendor-owned page.
  • Every remaining miss is listed on the page. Gold labels were drafted blind by separate agents; human review status is shown on the page.
